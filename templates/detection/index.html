Project Overview

About The Project

⚠️

Problem Statement

Cyber threats can be hidden within complex network traffic and may be difficult to identify manually. Modern attackers leverage sophisticated, high-speed unidirectional packet flows, making traditional rule-based firewalls insufficient.

💡

Proposed Solution

The system uses machine learning to analyze network traffic features and classify traffic as normal or malicious. By analyzing statistical flow metrics, transmission rates, and TCP dynamics, threats are flagged in real-time.

📊

Dataset & AI Model

Trained on the comprehensive UNSW-NB15 cybersecurity benchmark dataset using a high-precision Random Forest Classifier model trained in Google Colab, leveraging scikit-learn pipelines.
